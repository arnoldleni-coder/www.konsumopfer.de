# Konsumopfer

Eine responsive One-Page-Website für ein unabhängiges Magazin über bewussten Konsum.

## Dateien

- `index.html` — semantische Seitenstruktur und Inhalte
- `styles.css` — responsives Editorial-Design ohne Framework
- `script.js` — mobiles Menü und Newsletter-Interaktion

Die Seite funktioniert vollständig statisch und kann direkt über GitHub Pages veröffentlicht werden.
